## 💡 Como penso os projetos

Procuro seguir um fluxo simples e orientado a resultados:

1. **Entender o problema** — identificar a necessidade e quem utilizará a solução.
2. **Organizar os dados** — estruturar tabelas, validar informações e definir relacionamentos.
3. **Analisar** — utilizar SQL para consultar dados e construir indicadores relevantes.
4. **Comunicar** — apresentar resultados em dashboards claros.
5. **Automatizar** — avaliar oportunidades de reduzir tarefas repetitivas com n8n.
