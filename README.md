### 📁 Projetos em Destaque

#### 🗄️ Banco de Dados — Operações Logísticas
Banco relacional em **PostgreSQL** (`operacoes_logisticas`) modelado do zero, com 9 tabelas: clientes, motoristas, caminhões, trailers, instalações, rotas, cargas, viagens e manutenção. Estruturado com chaves primárias, chaves estrangeiras e integridade referencial completa.

> 🔗 Repositório em construção — link será adicionado em breve.

#### 📊 Dashboard — Receita e Clientes (Power BI)
Dashboard construído a partir do banco de Operações Logísticas, com:
- KPIs de receita total, peso transportado e volume de cargas
- Gráfico de receita por cliente
- Distribuição de cargas por tipo
- Evolução mensal de receita
- Ranking dos clientes com maior faturamento
